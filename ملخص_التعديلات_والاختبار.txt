═══════════════════════════════════════════════════════════════════

الخطوة 1: تأكد من تشغيل التطبيق
---------------------------------------
افتح PowerShell وشغل:

    cd C:\src\BACK\StoreManagement\src\StoreManagement.Web
    dotnet run

انتظر حتى ترى: "Now listening on: https://localhost:44339"


الخطوة 2: اختبر تسجيل الدخول
---------------------------------------
افتح PowerShell جديد وشغل هذا الكود:

[System.Net.ServicePointManager]::ServerCertificateValidationCallback = {$true}

$body = "grant_type=password&client_id=StoreManagement_Mobile&username=admin&password=1q2w3E*&scope=address email phone profile roles offline_access StoreManagement"

$response = Invoke-RestMethod -Uri "https://localhost:44339/connect/token" -Method POST -ContentType "application/x-www-form-urlencoded" -Body $body

Write-Host "Success! Token received:" -ForegroundColor Green
$response | ConvertTo-Json


✅ إذا نجح الطلب = كل شيء يعمل!
❌ إذا فشل = شوف الخطأ في نهاية هذا الملف

❓ إذا واجهت مشكلة "unauthorized_client":
═══════════════════════════════════════════════════════════════════

1. تأكد من إيقاف التطبيق:
   Get-Process -Name "dotnet" | Stop-Process -Force

2. احذف Mobile Client القديم:
   sqlcmd -S "(LocalDb)\MSSQLLocalDB" -d StoreManagement -E -i "C:\src\BACK\StoreManagement\reset-mobile-client.sql"

3. أعد تشغيل DbMigrator:
   cd C:\src\BACK\StoreManagement\src\StoreManagement.DbMigrator
   dotnet run

4. شغل التطبيق من جديد:
   cd C:\src\BACK\StoreManagement\src\StoreManagement.Web
   dotnet run

5. جرب مرة أخرى!
