🎯 الطريقة الأولى: من PowerShell (الموصى بها)
═══════════════════════════════════════════════════════════════════

1️⃣ افتح PowerShell
2️⃣ نفذ الأوامر التالية:

cd C:\src\BACK\StoreManagement\src\StoreManagement.Web
dotnet run

3️⃣ انتظر حتى ترى:
   [INF] Now listening on: https://localhost:44339
   [INF] Now listening on: http://localhost:5000
   [INF] Application started.

4️⃣ المشروع الآن يعمل!
   - HTTPS: https://localhost:44339
   - HTTP: http://localhost:5000
   - Swagger: https://localhost:44339/swagger

═══════════════════════════════════════════════════════════════════
❗ حل المشاكل الشائعة:
═══════════════════════════════════════════════════════════════════

مشكلة: Port already in use
الحل:
  netstat -ano | findstr "5000"
  taskkill /PID <PID_NUMBER> /F

مشكلة: Database connection error
الحل:
  cd C:\src\BACK\StoreManagement\src\StoreManagement.DbMigrator
  dotnet run

مشكلة: SSL Certificate error
الحل:
  استخدم HTTP بدلاً من HTTPS للتطوير
  http://localhost:5000
